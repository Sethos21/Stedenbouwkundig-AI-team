## Uitgevoerd en besluiten

Voor de start en voor publicatie is GitHub gecontroleerd op actieve runs, een taakbranch, een PR en issuecomments. Bij de start was ook geen open issue met de marker `[IN_UITVOERING]` zichtbaar. Dit zijn waarnemingen van zichtbare GitHub-status op de controlemomenten.

De GitHub-controller gebruikt nu dezelfde redirect-blokkerende HTTP-laag als OpenAI. Daarmee komt de HTTP-status rechtstreeks uit de HTTP-respons en blijft de log onafhankelijk van fouttekst. Paginering blijft op de vaste GitHub-origin. De preflight is de standaardmodus van handmatige dispatch en gebruikt alleen twee GET-verzoeken met gescheiden credentials. De OpenAI-check vraagt metadata op voor het geconfigureerde model. De claim-, uitvoer- en publicatierechten blijven gescheiden. De master-ruleset en de applicatieroute via HumanApprovalService zijn buiten de wijziging gebleven.
